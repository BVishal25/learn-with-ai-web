# Learn (with) AI: Interactive AI Learning Platform

This repository contains an interactive, gamified platform for learning about Artificial Intelligence, from foundational concepts to advanced topics.

## How It Works

This application is built on two fundamental principles:

### 1. Secure Authentication via Google Sign-In

The application uses Google Sign-In as its exclusive method for user authentication. There is no demo or guest mode. This ensures that each user has a unique identity to track their progress, notes, and personalized settings. To enable this, the application deployer **must** provide a valid Google Client ID.

### 2. User-Managed AI Provider Keys

To manage API costs and empower users, this application requires you to use your own API keys. In the **Settings** menu, you can select from a wide range of AI providers (like Google Gemini, Anthropic Claude, OpenAI, and more) and enter your corresponding API key. The key is stored securely in your browser's local storage and is used for all AI-powered features.

This model gives you full control over your API usage and allows you to experiment with different models.

## Run Locally

**Prerequisites:** Node.js, npm

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Configure Environment Variables:**
    Create a `.env.local` file in the root of the project. This file is for local development and should **not** be committed to source control. Add your Google Client ID to it:

    ```
    # .env.local
    VITE_GOOGLE_CLIENT_ID="YOUR_GOOGLE_CLIENT_ID_HERE"
    ```
    *To get a Google Client ID, visit the [Google Cloud Console](https://console.cloud.google.com/apis/credentials), create an OAuth 2.0 Client ID for a "Web application", and make sure to add `http://localhost:5173` (or your dev server's address) to the "Authorized JavaScript origins".*

3.  **Run the development server:**
    ```bash
    npm run dev
    ```
4.  Open the app in your browser and sign in with Google.
5.  Go to **Settings**, select your preferred AI Provider, and add your API Key to enable the AI features.

## Deploying to the Web

You have two main options for deployment. For most users, deploying to a static hosting service is the simplest method.

### Option 1: Static Host (Recommended)

This is the easiest way to get your app online. Services like Vercel, Netlify, or GitHub Pages are perfect for this.

1.  **Build the application:**
    ```bash
    npm run build
    ```
    This command creates a `dist` directory with all the production-ready static files.

2.  **Deploy:**
    Upload the contents of the `dist` directory to your hosting provider.

3.  **Configure Environment Variables on the Host:**
    In your hosting provider's project settings, you **must** add your Google Client ID as an environment variable:
    -   **Name:** `VITE_GOOGLE_CLIENT_ID`
    -   **Value:** `YOUR_GOOGLE_CLIENT_ID_HERE`

4.  **Update Authorized Origins:**
    Remember to add your live production URL (e.g., `https://your-app.vercel.app`) to the "Authorized JavaScript origins" in your Google Cloud Console credentials.

### Option 2: Using Docker

If you prefer a containerized environment, you can use the provided Dockerfile.

1.  **Build the Docker image:**
    From the root directory of the project, run:
    ```bash
    docker build -t learn-with-ai .
    ```

2.  **Run the Docker container:**
    You must provide your Google Client ID as an environment variable when running the container.

    ```bash
    docker run -p 8080:80 \
      -e VITE_GOOGLE_CLIENT_ID="YOUR_GOOGLE_CLIENT_ID_HERE" \
      --name learn-with-ai-app \
      -d learn-with-ai
    ```
    - `-p 8080:80`: Maps port 8080 on your local machine to port 80 inside the container.
    - `-e VITE_GOOGLE_CLIENT_ID`: Sets the required environment variable.
    - `--name learn-with-ai-app`: Gives the container a memorable name.
    - `-d`: Runs the container in detached mode (in the background).

3.  **Access the app:**
    Open your browser and navigate to `http://localhost:8080`.
